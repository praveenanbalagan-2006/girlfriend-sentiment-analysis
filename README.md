# girlfriend-sentiment-analysis
Human communication, especially in personal relationships, often carries emotional subtext that is difficult to interpret. Sentences like “I’m fine”, “Do what you want”, or “K.” can express a variety of sentiments beyond their literal meaning. This project aims to address the challenge of accurately identifying the emotional context of girlfriend-related conversations using Natural Language Processing (NLP) and machine learning techniques. By classifying messages into sentiment categories (Positive, Negative, Neutral) and detecting deeper emotions (like anger, joy, sadness), the system can help interpret nuanced communication..
